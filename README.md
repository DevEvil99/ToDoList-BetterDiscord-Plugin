## Default Shortcuts

| Action              | Default Shortcut   
|---------------------|--------------------
| Open New Task       | `Alt + T`          
| Open To-Do Inbox    | `Alt + I`          

You can disable shortcuts completely or set your own combination in the plugin settings.
