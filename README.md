# ToDoList 
ToDoList lets you create, manage, and track tasks with priorities, due dates, notes, and a clean inbox.

💡 If you find any bugs or have suggestions, please report them on my [Discord server](https://dsc.gg/devevil). 💡

## How to Use ToDoList

1. **Click on the list icon**  
   Look at the sidebar (server list).  
   You’ll see a **list/checklist icon** below the Discord logo (Direct Messages).  
   Click it to open the **New To-Do** modal.

   ![image](https://github.com/user-attachments/assets/ecd9adfb-6678-4cb6-ba89-092ff3130bd4)
   

2. **Create a task**  
   In the modal that appears, fill in:  
   - **Task** – the main thing you need to do  
   - **Due Date** (Optional) – pick date + time  
   - **Priority** – Low, Medium, or High  
   - **Notes** (Optional) – any extra details or reminders  

   Click **Add To-Do** when ready.

3. **View and manage your tasks**  
   - Inside the to-do modal → click **View All To-Dos** at the bottom  
   - Or use the shortcut **Alt + I** (default)  

4. **In the Inbox you can**  
   - See all tasks (or filter: All / Active / Completed)  
   - Search by task name or notes  
   - Sort by due date, priority, or newest  
   - Check/uncheck tasks
   - Edit tasks
   - Delete tasks

5. **Quick shortcuts**
   - **Alt + T** → open New To-Do modal  
   - **Alt + I** → open Inbox directly  

6. **Customize behavior**  
   - Turn shortcuts on/off  
   - Change key combinations  
   - Hide completed tasks by default when opening the inbox
